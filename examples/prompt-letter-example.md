# 综合评价提示函功能使用示例

## 示例场景

假设我们需要为"陕西文化产业融资担保有限公司"生成一份2025年上半年的综合评价提示函。

## 准备资料

### 一部资料（Word文档）
- 文件名：`综合评价提示函-陕西文化产业融资担保有限公司.docx`
- 包含信息：
  - 机构名称：陕西文化产业融资担保有限公司
  - 联系人：童彦 董事长
  - 业务指标数据：
    - 新增担保业务规模：目标30亿，实际28.5亿
    - 银担分险业务占比：目标60%，实际65%
    - 新增比例再担保业务规模：目标25亿，实际26.8亿
    - 小微三农融资担保业务占比：目标80%，实际82.5%
    - 担保放大倍数：目标6.0倍，实际6.2倍
    - 比例再担保业务代偿率：目标≤2%，实际1.8%

### 三部资料（Excel表格）
- 文件名：`担保机构名单-业务三部填写部分-2025.xlsx`
- 包含信息：
  - 代偿追偿数据
  - 个性化问题和建议

## 操作步骤

1. 访问系统，点击左侧菜单中的"综合评价提示函"
2. 在左侧区域点击"点击上传文件"按钮
3. 选择上述两个文件进行上传
4. 点击"上传全部"按钮
5. 上传完成后，点击"生成全部"按钮
6. 系统开始流式生成提示函
7. 在右侧主界面查看生成的提示函
8. 如需下载，选择相应文件并点击"导出"按钮

## 功能优势

1. **自动化程度高**：只需要上传原始资料，系统自动解析数据并生成标准化文档
2. **可视化操作**：清晰的上传进度和生成状态反馈
3. **批量处理**：可同时处理多个机构的资料
4. **灵活预览**：支持选择不同的生成结果进行预览对比
5. **便捷导出**：一键导出生成的文档

## 技术特点

- 前端采用React组件化架构，提供流畅的用户体验
- 后端使用Next.js API路由处理文件上传和文档生成
- 采用流式响应技术，实时反馈生成进度
- 支持多种文件格式的智能识别和解析
