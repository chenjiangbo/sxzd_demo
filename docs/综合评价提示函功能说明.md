# 综合评价提示函功能说明

## 功能概述

综合评价提示函功能允许用户上传一部和三部的资料文件，通过AI技术自动生成标准化的综合评价提示函。该功能参考了授信报告和机构评价报告的UI风格，提供了流式的文档生成体验。

## 功能特点

1. **文件上传区域（区域A）**：
   - 支持上传一部的Word文档和三部的Excel表格
   - 文件类型自动识别（根据文件名或扩展名）
   - 实时上传进度显示
   - 文件列表管理（查看、删除）

2. **批量处理能力**：
   - 支持批量上传多个文件
   - 一键生成多个提示函
   - 生成进度实时跟踪

3. **流式生成体验**：
   - AI生成过程可视化
   - 实时状态更新
   - 内容逐步呈现

4. **预览和导出**：
   - 右侧主界面实时预览生成的提示函
   - 支持选择不同生成的文档进行预览
   - 提供导出功能，可下载为HTML格式

## 技术实现

1. **前端组件**：
   - 主页面：`app/prompt-letter/page.tsx`
   - 预览组件：`components/PromptLetterPreviewClient.tsx`

2. **API路由**：
   - 生成路由：`app/api/prompt-letter/generate/route.ts`
   - 上传路由：`app/api/prompt-letter/upload/route.ts`
   - 导出路由：`app/api/prompt-letter/export/route.ts`

3. **服务层**：
   - 数据处理：`lib/server/prompt-letter/index.ts`

## 使用流程

1. 点击左侧导航栏中的"综合评价提示函"
2. 在左侧区域上传一部和三部的资料文件
3. 点击"上传全部"按钮上传所有文件
4. 点击"生成全部"按钮开始生成提示函
5. 在右侧主界面查看生成的提示函
6. 选择特定提示函进行预览
7. 点击"导出"按钮下载生成的文档

## 提示函格式

生成的提示函遵循标准格式，包含：

- 标题（机构名称和报告期间）
- 称呼（联系人信息）
- 总体情况分析
- 业务指标完成情况
- 年度目标任务
- 结尾祝福语
- 发函单位和日期

## 数据处理

系统会自动解析上传的文档，提取以下信息：

- 机构基本信息（名称、联系人、职务等）
- 6项核心业务指标
- 代偿追偿数据
- 个性化问题和建议（2026年新增）

## 技术架构

- 前端：React + Next.js Client Components
- 后端：Next.js Server Actions 和 API Routes
- 文件上传：FormData API
- 流式生成：Server-Sent Events (SSE)
- 文档格式：HTML 输出
