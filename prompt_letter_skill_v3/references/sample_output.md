## 关键学习点

### 1. 指标完成率格式
```
目标值XX亿元，实际值XX亿元，完成率XX%
目标值XX%，实际值XX%，完成率XX%
目标值XX倍，实际值XX倍，完成率XX%
```

### 2. 问题描述句式
```
贵司全年指标任务中{指标1、指标2、指标3}指标完成情况与时间节点要求{有一定差距/有较大差距}。
```
- 完成率<60%通常用"有较大差距"
- 完成率60%~99%通常用"有一定差距"
- 但咸阳市完成率64.87%用"有较大差距"，说明还需结合实际情况

### 3. 建议1格式（有问题的机构）
```
一是全力完成{year}年度各项目标任务。贵司全年指标任务中{指标列表}指标完成情况与时间节点要求{差距程度}，建议压实责任，切实把工作落到实处，坚决保质保量完成年度任务目标；
```

### 4. 建议1格式（无问题的机构）
```
一是全力完成{year}年度各项目标任务。压实责任，切实把工作落到实处，坚决保质保量完成年度任务目标；
```

### 5. 代偿率风险等级
| 代偿率范围 | 描述 |
|------------|------|
| > 5% | 已超过5%，合作业务风险明显提升 |
| > 3% 且 ≤ 5% | 超过3%，合作业务风险较高 |
| > 2% 且 ≤ 3% | 无单独风险提示 |
| ≤ 2% | 正常 |

### 6. 注意事项
- 金额单位是"亿元"，不是"万"
- 完成率保留2位小数
- 问题指标之间用"、"(顿号)分隔
- 代偿数据单位是"元"，展示时转亿元
- 建议4加强版：有个性化代偿问题时使用
