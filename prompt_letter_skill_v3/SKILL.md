# 陕西省信用再担保有限责任公司 提示函生成 Skill

## 概述

本 Skill 用于根据各融资担保机构存储于数据库中的业务数据（或从非结构化文档提取的数据），自动生成"综合评价提示函"。

**输入**：
1. **优先方案**：数据库中的机构业务数据
2. **备选方案**：从非结构化文档提取（一部的docx模板 + 三部的xlsx表格）

**输出**：格式规范的提示函文档（.docx）
**适用季度**：任意季度（2025年上半年、2025年下半年、2026年上半年等）

---

## 三、数据处理规则

### 3.1 完成率计算

```
完成率 = 实际值 / 目标值 × 100%
结果保留2位小数
```

**空值处理：**
- 目标值为0或null：完成率显示 "—"（不参与问题判定）
- 实际值为空：显示 "数据待填报"（不参与问题判定）
- 银担分险实际值为0：完成率计为0%，归入"有较大差距"

### 3.2 单位换算

| 类型 | 原始单位 | 展示单位 | 处理方式 |
|------|----------|----------|----------|
| 金额类 | 元 | 亿元 | 除以1亿，保留2位小数 |
| 百分比 | % | % | 直接使用 |
| 倍数 | 倍 | 倍 | 直接使用 |

## 四、问题判定规则

### 4.1 指标问题判定

遍历6项指标（代偿率除外），完成率 < 100% 纳入问题列表：

| 完成率范围 | 差距描述 | 示例 |
|------------|----------|------|
| < 60% | 有较大差距 | 36.57%、31.65%、29.67% |
| 60% ~ 99% | 有一定差距 | 81.38%、89.2%、85% |
| ≥ 100% | 不纳入问题 | |

### 4.2 2026年个性化问题判定

当存在以下个性化问题时，必须纳入"二、存在问题"：

| 问题类型 | 判定条件 | 描述模板 |
|----------|----------|----------|
| 数据质量问题 | data_modify_count > 0 | 贵司2026年1-4月累计修改字段{data_modify_count}个，其中一级字段xx个，数据修改频次偏高 |
| 创新产品问题 | 有民间投资专项担保计划任务 | 创新担保产品研发力度有待加强，产品体系较为单一，市场适配性不足，民间投资担保专项计划推进力度有待加强，需加快推进落实，抓实专项业务拓展 |
| 风险防控问题 | 普遍性风险问题 | 产品风险防控不够细化，产品设计高度依赖银行，未能基于细分的客群建立差异化的产品，存量风险转嫁现象时有发生，穿透审核能力有待加强 |
| 追偿问题 | 有代偿数据且返还率低 | 追偿及返还工作力度还显不足，追偿返还体制机制有待完善，抵债资产变现能力较弱，返还项目未及时完成国担基金SaaS系统返还申报程序 |

### 4.3 代偿率风险判定

| 代偿率范围 | 描述方式 |
|------------|----------|
| ≤ 2% | 正常展示，句末加"合作业务风险可控。" |
| > 2% 且 ≤ 3% | 正常展示，无额外风险提示 |
| > 3% 且 ≤ 5% | 句末加"合作业务风险较高。" |
| > 5% | 在问题章节中强调："合作业务担保代偿率处于高位水平，需加强风险把控。" |

### 4.4 代偿追偿问题判定

| 条件 | 描述 |
|------|------|
| 累计代偿 > 0 且 累计回收 = 0 | "代偿补偿项目尚未实现资金回流，追偿工作力度有待加强。" |
| 累计代偿 > 0 且 返还率 < 50% | 追加："代偿款返还率偏低，建议加大追偿力度。" |

### 4.5 "二、存在问题"章节显示规则

| 情况 | 是否显示 |
|------|----------|
| 有问题指标 或 代偿率风险 > 3% 或 有个性化问题 | 显示 |
| 无问题指标 且 代偿率正常 且 无个性化问题 | 省略（直接进入"三、相关建议"） |

## 八、非结构化文档解析规则（备选方案）

### 8.1 数据来源

| 来源 | 文档类型 | 说明 |
|------|----------|------|
| 业务一部 | 综合评价提示函-xxx.docx | 含6项指标数据和机构信息 |
| 业务三部 | 担保机构名单-业务三部填写部分xxxx.xlsx | 含代偿追偿数据、个性问答 |

### 8.2 一部docx解析规则

**机构信息提取：**
- 机构名称：从第一行提取，格式：`关于{机构名}{year}年上/下半年综合评价的提示函`
- 联系人/职务：从第二行提取，**提取实际姓名和职务填入输出，如 "童彦董事长："、"张宇婷："**，**不要保留占位符格式**
- 报告期：从"截至xxxx年末/三季度末"提取

**6项指标提取：**
从"（一）/一、"段落中提取，格式示例：
```
截至{report_period}，新增担保业务规模目标值{值}亿元，实际值{值}亿元，完成率{值}%；银担分险业务占比目标值{值}%，实际值{值}%，完成率{值}%
```

**代偿数据：**
- docx中用`**`表示数据待确认，需从xlsx补充
- 例如：`累计代偿补偿金额**，累计回收**，{year}年回收**，代偿款返还率**`

### 8.3 三部xlsx解析规则

**代偿追偿数据：**
从列`代偿追偿及返还情况截至xxxx年x季度末...`提取，格式示例：
```
截至2025年三季度末，累计代偿补偿金额25763046.60元，累计回收3099999.60元，2025年回收0元，代偿款返还率12.03%。
```

**2026年数据修改问题：**
从相关列提取"1-4月累计修改字段xx个"等描述。

**个性问答：**
- 从列`二、存在问题`提取问题描述
- 从列`三、相关建议`提取建议内容

### 8.4 数据合并规则

| 来源 | 用途 | 说明 |
|------|------|------|
| 一部docx | 机构信息、6项指标 | 完整提取 |
| 三部xlsx | 代偿追偿数据 | 补充docx中的`**` placeholder |
| 三部xlsx | 个性问题/建议 | 直接追加到固定模板后 |

## 九、输出格式模板

### 9.1 2026年上半年-有代偿数据时


## 十一、生成流程

### 11.1 优先方案（数据库）

1. **接收指令**：用户要求生成某机构某季度的提示函
2. **识别时期**：根据年度和报告期判断是2025上半年/下半年还是2026上半年
3. **读取数据**：从数据库获取机构信息、6项指标、代偿数据、个性问题/建议、数据质量问题
4. **计算完成率**：遍历6项指标，标记问题指标
5. **判定风险**：检查代偿率是否超过阈值
6. **组装问题列表**：根据指标问题 + 代偿率风险 + 个性问题，生成"二、存在问题"
7. **生成建议**：根据时期和有代偿数据，生成对应条数的建议
8. **填充模板**：组装完整提示函文本
9. **输出文档**：生成 .docx 文件

### 11.2 备选方案（非结构化文档）

1. **接收指令**：用户提供一部docx + 三部xlsx
2. **识别时期**：根据报告期判断时期类型
3. **解析一部docx**：提取机构名称、联系人、6项指标
4. **补充三部xlsx**：提取代偿数据、个性问答、2026年数据质量问题
5. **合并数据**：将提取的数据转为结构化格式
6. **计算完成率**：遍历6项指标，标记问题指标
7. **判定风险**：检查代偿率是否超过阈值
8. **组装问题列表**：根据指标问题 + 代偿率风险 + 个性问题，生成"二、存在问题"
9. **生成建议**：根据时期和有代偿数据，生成对应条数的建议
10. **填充模板**：组装完整提示函文本
11. **输出文档**：生成 .docx 文件

## 十四、2026年特殊规则

### 14.1 数据质量问题表述

当 `data_modify_count > 0` 时，在问题章节加入：
```
一是贵司2026年1-4月累计修改字段{data_modify_count}个，其中一级字段{level1_count}个、其他字段{other_count}个，集中在共同借款人等关键信息项，数据修改频次偏高；
```

### 14.2 民间投资专项担保计划表述

当有民间投资专项担保计划任务时：
1. 在年度任务目标中加入"年度新增民间投资专项担保计划规模{值}亿元"
2. 在存在问题中加入创新产品问题描述
3. 在建议中加入"加强产品创新研发"一条

### 14.3 风险描述插入位置

- ≤ 2%：在代偿率数据后加"合作业务风险可控。"
- > 3% 且 ≤ 5%：在代偿率数据后加"合作业务风险较高。"
- > 5%：在问题章节第一条中强调
